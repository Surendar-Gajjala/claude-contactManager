# Project Overview

A simple full-stack Contact Management application for managing Persons and their Contacts (phone numbers), with search, pagination, sorting, form validation, and bulk creation through Excel upload.

# Database Details

Database: PostgreSQL
properties
url=jdbc:postgresql://localhost:5432/contact_manager
username=postgres
password=postgres

## Database Tables

persons
contacts

### Persons Table Details
 Column       Type            Constraints                                    
 id           BIGSERIAL       PRIMARY KEY                                    
 first_name   VARCHAR(100)    NOT NULL                                       
 last_name    VARCHAR(100)    NOT NULL                                       
 email        VARCHAR(255)    NOT NULL, UNIQUE                               
 gender       VARCHAR(20)     NOT NULL, CHECK IN (MALE, FEMALE, OTHER) 
 address      VARCHAR(255)    NOT NULL                                       
 createdDate  TIMESTAMP       NOT NULL, DEFAULT now()                        
 updatedDate  TIMESTAMP       NOT NULL, DEFAULT now()                        

### Contacts Table Details
 Column         Type           Constraints                                               
 id             BIGSERIAL      PRIMARY KEY                                               
 person_id      BIGINT         NOT NULL, FOREIGN KEY REFERENCES persons(id)              
 phone_number   VARCHAR(20)    NOT NULL                                                  
 contact_type   VARCHAR(20)    NOT NULL, CHECK IN (MOBILE, HOME, WORK, PERSONAL) 
 createdDate    TIMESTAMP      NOT NULL, DEFAULT now()                                   
 updatedDate    TIMESTAMP      NOT NULL, DEFAULT now()

Example:

 FirstName  LastName  Email                                            Gender  Address    PhoneNumbers            ContactType    
 ---------  --------  -----------------------------------------------  ------  ---------  ----------------------  -------------- 
 Surendar   Reddy     [surendar@gmail.com](mailto:surendar@gmail.com)  MALE    Hyderabad  9618443676, 7893097820  HOME, PERSONAL 


# Excel Phone Number and Contact Type Mapping

The Excel file must contain the following columns:
PhoneNumbers, ContactType

Both fields can contain multiple comma-separated values.

## Example
If an Excel row contains:
PhoneNumbers: 9618443676, 7893097820
ContactType: HOME, PERSONAL

The application must process the values individually.
## Processing Rules

1. Split the PhoneNumbers value using a comma (,).
2. Split the ContactType value using a comma (,).
3. Trim leading and trailing spaces from each value.
4. Create a separate Contact record for each phone number.
5. Map each phone number to the corresponding Contact Type based on its position.
6. The first phone number must be mapped to the first Contact Type.
7. The second phone number must be mapped to the second Contact Type.
8. Continue the same positional mapping for all values.
9. All Contacts created from the same Excel row must be associated with the same Person.

## Expected Result
PhoneNumbers: 9618443676, 7893097820
ContactType: HOME, PERSONAL

Create two Contact records for the same Person:

 Person          Phone Number  Contact Type 
 --------------  ------------  ------------ 
 Surendar Reddy  9618443676    HOME         
 Surendar Reddy  7893097820    PERSONAL     

# Excel Validation Rules

The number of phone numbers must exactly match the number of contact types.

### Valid Example
PhoneNumbers: 9618443676, 7893097820
ContactType: HOME, PERSONAL
There are:
2 phone numbers
2 contact types

Therefore, the row is valid.
### Invalid Example
PhoneNumbers: 9618443676, 7893097820
ContactType: HOME

There are:
2 phone numbers
1 contact type

Therefore, the row is invalid.
The system must:

 Reject the invalid Excel row.
 Return a clear validation error.
 Not create incomplete or incorrectly mapped Contact records.

Excel processing should validate the complete row before persisting the corresponding Person and Contacts to avoid partial or inconsistent data.

The upload API should also validate:
 Required Excel columns
 Empty required values
 Email format
 Gender values
 Phone number format
 Contact Type values
 Duplicate email addresses
 Phone number and Contact Type count mismatch
 Invalid or unsupported Excel file format
